# Nombre del script

Qué hace, en una o dos frases.

## Uso

1. Qué tiene que estar abierto o seleccionado en Resolve (proyecto, carpeta del Media Pool, timeline…).
2. **Workspace → Scripts → nombre_del_script**.
3. Qué cambia en el proyecto y qué no toca nunca.

Los mensajes salen en **Workspace → Console**.

## Opciones

| Opción | Qué hace |
|---|---|
| `greeting` | Ejemplo: el texto del saludo. |

## Requisitos y límites

- Python 3 de 64 bits (lo necesita Resolve para los scripts `.py`).
- Qué no hace o dónde puede fallar.
